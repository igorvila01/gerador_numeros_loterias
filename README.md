🎲 Gerador de Números da Loteria
📌 Sobre
Este projeto é um gerador de números aleatórios para jogos de loteria.
A ideia é praticar conceitos de Python como geração de números aleatórios, funções e interação com o usuário.

🚀 Funcionalidades
Gera combinações de números aleatórios para diferentes tipos de loteria.

Permite personalizar a quantidade de números gerados.

Código simples e fácil de entender, ideal para estudos.

🛠️ Tecnologias utilizadas
Linguagem: Python 3

Biblioteca: random

▶️ Como executar
Clone este repositório e execute o script principal:

bash
git clone https://github.com/igorvila01/gerador_numeros_loterias
cd gerador_numeros_loterias
python gerador.py
📂 Estrutura
gerador.py → script principal que gera os números

README.md → documentação do projeto

🎯 Objetivo
Este projeto foi desenvolvido para fins de estudo e prática em Python.
Não garante resultados reais em jogos de loteria — é apenas uma simulação divertida.
